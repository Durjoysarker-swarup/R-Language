# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, inclusive, and harassment-free environment for all contributors, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, sex, sexual orientation, or any other characteristic.

## Expected Behavior

We expect all community members to:

- **Be Respectful**: Treat others with respect and dignity
- **Be Inclusive**: Welcome and support people of all backgrounds
- **Be Professional**: Communicate in a professional and constructive manner
- **Be Collaborative**: Work together toward common goals
- **Be Honest**: Acknowledge mistakes and learn from feedback
- **Be Patient**: Remember that people are learning and growing

## Unacceptable Behavior

We do not tolerate:

- **Harassment**: Sexual harassment, bullying, intimidation, or threats
- **Discrimination**: Discrimination based on protected characteristics
- **Offensive Language**: Slurs, profanity, or derogatory language
- **Spam**: Unwanted promotional content or mass messaging
- **Trolling**: Deliberately provoking or irritating others
- **Doxxing**: Sharing private information without consent
- **Other Harmful Conduct**: Any behavior that creates a hostile environment

## Reporting Violations

If you witness or experience behavior that violates this code of conduct:

1. **Document**: Note what happened, when, and who was involved
2. **Report**: Contact the maintainers at [contact@example.com](mailto:contact@example.com)
3. **Provide Details**: Include as much relevant information as possible
4. **Keep Confidential**: Do not publicly discuss the report unless directed to do so

All reports will be:
- Taken seriously
- Investigated promptly
- Handled confidentially
- Acted upon appropriately

## Enforcement

Maintainers will review reported violations and may:

1. **Warn** the individual about the conduct
2. **Request Apology** or clarification
3. **Remove Content** that violates this code
4. **Suspend** privileges temporarily
5. **Ban** individuals who repeatedly violate the code

## Scope

This code of conduct applies to:
- GitHub issues, discussions, and pull requests
- Comments on repository content
- External project spaces using the project name
- Interactions on social media related to the project
