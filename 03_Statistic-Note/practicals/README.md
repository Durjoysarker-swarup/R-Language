# Statistics Practicals

This folder contains the practical exercise files that complement the statistical theory in `03_Statistic-Note/notes`. These materials are intended for hands-on practice after reading the corresponding notes.

## Folder structure

```text
03_Statistic-Note/practicals/
├── 01_Introduction_Practical.pdf
├── 02_Measures_of_Location_Practical.pdf
├── 03_Measure_of_dispersion.pdf
├── 04_Corelation_and_Regression_Practical.pdf
├── 05_Test_of_Hypothesis_Practical.pdf
├── 06_Design_of_Experiment_Practical.pdf
└── README.md
```

## Topics covered

- Introduction practical
- Measures of location
- Measures of dispersion
- Correlation and regression
- Test of hypothesis
- Design of experiment

## Purpose of this folder

The practical files help learners apply the concepts from the notes in a structured, step-by-step way. They are useful for understanding how statistics works in real problems and for preparing for analysis in R.

## Suggested workflow

1. Read the matching note file.
2. Work through the corresponding practical file.
3. Practice the method again with your own data or the repository examples.
4. Use the knowledge in later experimental design analysis.

## Relation to the repo

This practical section is closely connected with the statistical theory in `03_Statistic-Note/notes` and the experimental work in `04_Design-of-Experiment`. Together they form a complete learning path for agricultural statistics and applied R analysis.
