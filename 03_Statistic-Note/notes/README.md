# Statistics Notes

This folder contains the core theory notes for the statistics section of the `R-Language` repository. These materials introduce the statistical concepts needed before moving into applied data analysis and experimental design.

## Folder structure

```text
03_Statistic-Note/notes/
├── 01_Introduction .pdf
├── 02_Measure_of_Location.pdf
├── 03_Measures_of_Dispersion.pdf
├── 04_Correlation_and_Regression .pdf
├── 05_Test_of_Hypothesis.pdf
├── 06_Design_of_Experiment.pdf
└── README.md
```

## Topics covered

- Introduction to statistics
- Measures of central tendency (location)
- Measures of dispersion
- Correlation and regression
- Hypothesis testing
- Design of experiments

## What these notes are for

These note files explain the theory behind the statistical methods used in the repository. They are the conceptual foundation for the practical exercises and the later R-based experimental design examples.

## Recommended learning flow

1. Start with the introduction notes.
2. Study measures of location and dispersion.
3. Learn correlation and regression.
4. Move to hypothesis testing.
5. Finish with design of experiments to prepare for `04_Design-of-Experiment`.

## Connection to the repo

This folder builds the statistical foundation for the analysis work in `01_Basic`, `02_Self-Learning`, and `04_Design-of-Experiment`. The concepts here are directly used in agricultural data analysis and experimental trial interpretation.
