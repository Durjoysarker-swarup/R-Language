# Statistics Notes

This folder contains the statistics learning materials used in the `R-Language` repository. It includes short notes and practical files covering basic statistical concepts and their application in data analysis.

## Folder structure

```text
03_Statistic-Note/
├── README.md
├── notes/
│   ├── 01_Introduction .pdf
│   ├── 02_Measure_of_Location.pdf
│   ├── 03_Measures_of_Dispersion.pdf
│   ├── 04_Correlation_and_Regression .pdf
│   ├── 05_Test_of_Hypothesis.pdf
│   └── 06_Design_of_Experiment.pdf
├── practicals/
│   ├── 01_Introduction_Practical.pdf
│   ├── 02_Measures_of_Location_Practical.pdf
│   ├── 03_Measure_of_dispersion.pdf
│   ├── 04_Corelation_and_Regression_Practical.pdf
│   ├── 05_Test_of_Hypothesis_Practical.pdf
│   └── 06_Design_of_Experiment_Practical.pdf
```

## Topics covered

- Introduction to statistics
- Measures of location
- Measures of dispersion
- Correlation and regression
- Test of hypothesis
- Design of experiment

## What these files are for

- `notes/`: theory and concept explanations
- `practicals/`: applied examples and exercises
- `pdf` files: lecture notes and study material

## How to use this folder

1. Read the theory in the `notes/` files first.
2. Practice with the corresponding `practicals/` files.
3. Use the learned concepts while working with agricultural and experimental data in the repository.

## Relation to the repo

This folder is the statistical foundation for the later experimental design work in `04_Design-of-Experiment`. Together, these folders help build a complete workflow for data analysis and agricultural statistics in R.
